# `public/.gitkeep`

Source: [`../../public/.gitkeep`](../../public/.gitkeep)

## Purpose

The empty `.gitkeep` preserves the `public/` directory in the repository until the storefront needs public assets such as icons, logos, or static images. It has no runtime behavior and is not served as an application asset.

## Maintenance boundary

Replace this placeholder only when a real public asset is added. Document each asset’s ownership and use in the corresponding feature documentation; do not put generated build output in this directory.
