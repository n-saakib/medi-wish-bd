# Product image browser journeys

Mirrors `tests/browser/productImagesUi.spec.ts`.

Runs the Ticket 15 Images card and modal against the migrated PostgreSQL-backed API and built frontend, using synthetic Products and generated image bytes. It reuses catalog actors and real catalog creation, and reads persisted image/catalog state after commands and reloads. It does not create a public Product page (Ticket 17 scope).

The fixed plan matrix covers E2E-15-14–24: Moderator upload with real optimized image decoding and dimensions, and Customer refusal; server validation; client size/type/extension prechecks with zero network requests; Ticket 14 catalog version, history, pricing and inactive-image compatibility; alt persistence/fallback; main/replacement/removal identity, confirmation and focus; keyboard, amber focus rings, and 44 px targets; 375/1280 px grid layouts; failure placeholders; Ticket 08 role demotion; upload busy guard, retained 503 retry and expired-token renewal of a valid large upload with explicit 401 then 201 and one refresh. Each case has `@t15` and exactly its plan sub-ticket tag; 14 also has `@smoke`.

Additional journeys cover quiet loading/empty states, load retry, missing Images card before Product creation, the eight-image limit, replacement at the limit, same-file input reset and fresh ids, racing image-limit refusal, terminal id conflicts, retained upload/replacement retry after 503, before persistence and after a lost response, stale alt/order intent, already-removed confirmation preservation of typed description on a dependency failure, and stored markup-like alt text rendered literally without event-handler injection or execution in the editor/dialog after reload. Successful requests reach the real backend. Interception is limited to deliberately delaying or failing network/dependency requests; a lost-response test forwards the request and asserts its real commit before aborting the browser response.

Private helpers scope Images controls by the design heading, drive real file chooser events (keyboard activation where applicable), await each upload response before reading success copy, observe multipart command ids and replacement targets, and measure labelled target sizes. `listImages` verifies actual persisted identities, order and metadata. Retries assert both request identity and exactly one persisted image, rather than merely counting rendered thumbnails.

Run with `npm run test:browser -- --grep '@t15'` or focus this file; Playwright uses the existing Chrome and Edge projects. A missing Ticket 15 implementation causes ordinary assertion failures. Tests contain no skips and do not claim implementation, external storage signoff, resource-load measurements or story completion.
