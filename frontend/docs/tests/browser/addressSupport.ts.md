# Ticket 12 browser support

Maps the accepted saved-address contract to synthetic real-API fixtures. `AddressApi` composes the existing `ProfileApi` token and MFA refresh behavior. It exposes create, read, edit, delete, Bearer headers and checked book reads; raw bodies remain available for malformed-input cases.

`syntheticAddress` produces unique canonical ids, synthetic names, address lines and 11-digit mobiles. `addressEdit` strips the read-only id. `expectAddressBook` verifies exact projection keys, at most three rows, one default when nonempty, valid versions, bounded allowance values, normalized safe free text, no-store and request correlation. Text must contain no controls or line/paragraph separators and already have Java `String.trim()` padding removed and ASCII-space runs collapsed; optional labels are null or nonempty. NBSP/FEFF-only values remain accepted. This oracle checks the backend's stored response contract. Contract copy is centralized in `addressCopy`.

`storedAddresses` and `storedAddressChanges` query only the run-owned PostgreSQL schema after `checkedTarget` validates the schema and synthetic username. They return persisted contract fields in PostgreSQL order and counted-change timestamps without writing data. `storedAddressState` uses the same guard and reads complete own `saved_addresses` and `saved_address_changes` rows via `to_jsonb`, preserving all columns including user identity, change IDs and creation/update timestamps. Exact before/after comparisons therefore detect incidental writes hidden by the DTO projection. `openAddresses` signs in and opens the real Addresses page; `addressDialog` selects its accessible dialog.

`assertAwayFromDhakaPeriodStart` refuses real-clock allowance checks within five minutes of Monday or month-start midnight in Asia/Dhaka. It checks the preceding and following local midnight, including month starts on a Sunday, and throws rather than silently skipping. Monthly and exact calendar-boundary enforcement requires the plan's controlled backend calendar tests.
