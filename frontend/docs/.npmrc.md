# `.npmrc`

Source: [`../.npmrc`](../.npmrc)

## Purpose

This project-local npm configuration makes dependency installation predictable.

- `save-exact=true` prevents future `npm install` commands from widening dependency ranges in `package.json`.
- `engine-strict=true` makes npm reject unsupported Node.js versions instead of continuing with an unverified runtime.

These settings reinforce the exact versions and Node.js `24.x` requirement declared in `package.json`.

## Verification

Run `npm ci` with the supported Node.js/npm pair. An unsupported Node version should fail early with an engine error rather than produce a misleading later build failure.
