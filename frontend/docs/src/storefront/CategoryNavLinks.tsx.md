# `src/storefront/CategoryNavLinks.tsx`

Source: [`src/storefront/CategoryNavLinks.tsx`](../../../src/storefront/CategoryNavLinks.tsx)

Client component that renders the first eight category destinations and an All categories link in a translated navigation landmark. Empty input produces no navigation. The links remain keyboard-accessible, and the horizontal bar scrolls within its own viewport on narrow screens.

The current-page mark comes from the rendered page, not the URL. `CurrentCategoryProvider` (mounted by the store layout around the bar and the page) holds one bar destination. `CurrentCategoryMark({ href })` is rendered by the category listing (`/categories/{id}`) and the category directory (`/categories`); it declares its destination after mount and clears it on unmount. `CategoryNavLinks` gives the declared link `aria-current="page"` and the design's `is-active` underline, so the state is shown by more than color. A store not-found or error view renders no mark, so a 404 on a listed category's URL (for example `?page=99`) marks no category. Product pages declare none, as before. Because the mark is set in an effect, it appears after hydration; server HTML carries no current mark.
