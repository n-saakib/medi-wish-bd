# `src/app/icon.svg`

Source: [`../../../src/app/icon.svg`](../../../src/app/icon.svg)

The site icon: the header's logo mark (a `#176b56` rounded square with a white plus), as one static SVG. Next.js links it from every page's `<head>`, so browsers stop requesting a missing `/favicon.ico` and a signed-out load writes no console error.
