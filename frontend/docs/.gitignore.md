# `.gitignore`

Source: [`../.gitignore`](../.gitignore)

## Purpose

This file keeps frontend dependencies, framework output, local credentials, reports, deployment metadata, IDE files, and local agent documentation out of Git.

## Ignored groups

- Dependency and build output: `node_modules`, `.next`, `out`, coverage, TypeScript build info, Storybook output.
- Generated framework metadata: `next-env.d.ts`.
- Test artifacts: test results and Playwright reports.
- Local runtime data: `.env*` except `.env.example`, logs (including the browser tests' `test-api.log`), and npm debug logs.
- Deployment and IDE metadata: `.vercel`, `.idea`, and IntelliJ module files.
- Local-only docs: `agent-docs` and `local-docs`.

The rules intentionally preserve `.env.example` as a safe template while excluding actual environment files. They do not ignore `frontend/docs`, so the checked-in code mirror remains reviewable.

## Verification

After adding or changing a generated/local file, check `git status --short` and `git check-ignore -v <path>`. Keep credentials and machine-specific settings outside commits.
