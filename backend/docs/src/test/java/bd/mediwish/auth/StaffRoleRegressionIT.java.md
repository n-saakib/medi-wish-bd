# StaffRoleRegressionIT.java

Real HTTP/PostgreSQL safeguards: Moderator reads, self-promotion and no-op requests remain403; only the provisioned Super Admin changes Admin; self and Super Admin changes are refused while current-role retries are harmless. Restricted staff are denied even Customer routes. Mass assignment, legacy bodies, numeric coercion, oversized bodies and non-JSON fail without writes. A deleted User's token is unauthorized.
