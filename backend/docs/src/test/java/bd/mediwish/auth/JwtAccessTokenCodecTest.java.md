# JwtAccessTokenCodecTest

Checks the issued identity/session claims, rejection of signed tokens missing any required claim, future-`iat` and expired-token rejection using the injected clock, and deterministic payload tamper rejection. Issuer/audience pinning, rejection of `alg=none`, a different HS256 key, HS512 even with the configured key, and an HS256 secret below the 32-byte minimum are also covered. Session ownership is checked separately by `SessionServiceTest`; session-family expiry and validly signed tokens whose `sub` or `sid` alone was changed are exercised at the real HTTP/PostgreSQL seam in `SessionIT` and `ProfileIT`.
