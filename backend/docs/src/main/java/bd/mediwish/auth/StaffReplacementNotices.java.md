# `StaffReplacementNotices.java`

Post-commit replacement notice coordinator. `notifyReplacement(userId)` reads the User without a lock and skips sending unless mobile is verified. It formats the externalized notice time in English using `Asia/Dhaka` and `d MMM yyyy, h:mm a`, then sends on its own virtual-thread executor. The configured timeout bounds the send; timeout/interruption cancels the task, with caller interruption preserved. Lookup, message construction, and adapter exceptions map to `FAILED`. Each outcome maps to a distinct `MFA_REPLACEMENT_NOTICE_*` audit event in a small transaction via `TransactionOperations`; audit failure does not alter the delivery outcome or hide fresh codes. No contact or text is logged. `close()` uses `@PreDestroy` to interrupt outstanding executor work. The recovery service calls this only after its replacement transaction returns. Verified email delivery and durable retries remain deferred to Tickets 05 and 26.
