# UserService

Registration application service for the shared User resource. It uses the shared `UserIdentifierNormalizer` seam for username, mobile and optional-email normalization, then bounds input, rejects null/blank or out-of-range passwords without transforming nonblank password text, checks username/mobile uniqueness, assigns the Customer role and stores only the encoded password verifier. It flushes the insert so a PostgreSQL uniqueness race (SQL state `23505`) is converted to the same bounded duplicate outcome as the pre-check; other data-integrity failures are preserved. Mobile format/country normalization, OTP verification and activation gating remain deferred to Ticket 61.
