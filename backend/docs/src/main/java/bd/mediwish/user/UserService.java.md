# UserService

Registration application service for the shared User resource. It uses the shared `UserIdentifierNormalizer` seam for username, mobile and optional-email normalization, then bounds input, checks username/mobile uniqueness, assigns the Customer role and stores only the encoded password verifier. The legacy static username helper remains as a compatibility bridge for existing callers while registration and Ticket 03 authentication use the injected normalizer. It flushes the insert so a PostgreSQL uniqueness race (SQL state `23505`) is converted to the same bounded duplicate outcome as the pre-check; other data-integrity failures are preserved. Mobile format/country normalization, OTP verification and activation gating remain deferred to Ticket 61.
