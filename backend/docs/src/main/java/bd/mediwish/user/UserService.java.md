# UserService

Registration application service for the shared User resource. It trims and lowercases usernames and optional email, trims and length-bounds mobile input without inventing a country-format rule, bounds email/password input, validates the reduced registration contract, checks username/mobile uniqueness, assigns the Customer role and stores only the encoded password verifier. The same username normalization is reused by the authentication lookup. It flushes the insert so a PostgreSQL uniqueness race (SQL state `23505`) is converted to the same bounded duplicate outcome as the pre-check; other data-integrity failures are preserved. Mobile format/country normalization, OTP verification and activation gating are intentionally deferred by the current development slice and Ticket 61.
